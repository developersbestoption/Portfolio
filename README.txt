# Mahammad Rafi Shaik — Portfolio

## Run locally
1. Keep `index.html` and the resume DOCX in the same folder.
2. Open `index.html` in a browser.

## Customize later
- Add live project URLs and GitHub repository links.
- Add coding profiles (for example, LeetCode) when you want them shown.
- Add verified achievements, awards, hackathons, or additional projects.
- Replace the resume DOCX with the latest version when updated.
